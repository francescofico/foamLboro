# cEpotBuoyantBulkFoam

## Description
Same as cEpotBuoyantFoam, but this solver allows for a variable bulk temperature.
Note that this might be not physical, depending on the function used to compute the bulk temperature.

The example shows two different ways to compute the bulk temperature.
## info

Tb is the bulk temperature for buoyancy computation - uses a coded function to update it at runtime.
