# epotFoamBuo: buoyant vertical duct, insulating walls, two heating orientations

Validation case. Fully developed natural convection in a long vertical square duct with differentially heated walls and a horizontal magnetic field. This is the fully established regime of Authié, Tagawa & Moreau (2003). It is the buoyant counterpart of `epotFoam_isoTh/shercliff_duct`: all walls are electrically insulating, and the net flow is zero. Two heating orientations are available:

| `--heating` | Heated walls | Temperature | Body force | Flow |
|---|---|---|---|---|
| `normal` (default) | side walls z = ∓a hot/cold | T = −z/2 | F z | up on the hot side, down on the cold side; the core flow varies across B |
| `parallel` | Hartmann walls y = ∓a hot/cold | T = −y/2 | F y | the flow varies along B and is strongly braked; it concentrates in the side layers |

## Run

```sh
./Allrun                      # heating normal to B, Ha = 100, Gr = 2e4, about 4.5 min
HEATING=parallel ./Allrun     # grad T along B
./Allclean
```

`validate.py` exits non-zero if an error is above 2 % (`--tol`) or the last write interval changed the velocity by more than 0.2 % (not steady).

## Problem definition

| Item | Value |
|---|---|
| Geometry | Square duct −a < y, z < a, x vertical. One periodic cell in x |
| Magnetic field | B0 = (0, B, 0) |
| Walls | No-slip, electrically insulating. Two are isothermal (T = ±0.5), the other two adiabatic, depending on `--heating` |
| Buoyancy | Body force Gr (T − T_ref) e_x from a coded fvOption (`constant/fvOptions`, generated by `setup.py`); `constant/g` = 0 |
| Units | Non-dimensional: a = ν = ρ = σ = β = ΔT = 1, so B = Ha; κ = 1/Pr |
| Default | Ha = 100, Gr = 2 × 10⁴ (so F = −10⁴), Pr = 0.01; mesh 80 × 80 as in shercliff_duct |
| Time step | 0.25/Ha². endTime = 10/Ha: this case settles with an e-folding time of about 1/Ha |

**Why a coded body force?** x is the periodic direction. A periodic `p_rgh` cannot carry a hydrostatic pressure that varies across the duct, so the solver's own buoyancy term cannot drive a streamwise flow in a periodic vertical domain. Here gravity is set to zero and the Boussinesq force is added explicitly. The solver's own buoyancy formulation is checked in `../buoyant_slot`, which has real end walls.

**What is (not) tested.** In fully developed vertical flow, u·∇T = 0, so T is pure conduction and does not depend on u. Gr and Pr only scale the result. The case tests the temperature equation, the buoyancy forcing and the MHD response. It does not test heat transport by the flow.

## Analytical solution
The same Fourier-series method as for Shercliff flow, with the uniform pressure gradient replaced by a body force linear in y or z (`../../common/mhdAnalytic.py`, `BuoyantDuctSolution`). For forcing in z the z-basis becomes sin(kπz) for u and cos(kπz) for φ. For forcing in y the y-dependence becomes odd. The implementation is checked against:
- an independent 2D finite-difference solution, which converges to it at second order for both orientations, with insulating and with thin conducting walls
- the wide-duct limit, the 1D buoyant Hartmann profile of `buoyant_slot` (to 3 × 10⁻⁷)

## Results (v2606, default mesh)

There is no net flow, so there is no pressure gradient to compare. The headline numbers are the peak velocities.

| heating | u_max: OpenFOAM | u_max: exact | error in u_max | max error in u | max error in φ | max error in T | run time |
|---|---|---|---|---|---|---|---|
| normal to B | 74.433 | 74.057 | 0.51 % | 0.52 % | 0.51 % | 5 × 10⁻¹⁰ | 4.5 min |
| parallel to B | 11.630 | 11.579 | 0.44 % | 0.93 % | 0.15 % | 2 × 10⁻⁹ | 2.3 min ¹ |

¹ Run to 5/Ha, where the change over the last write interval was already 5 × 10⁻⁶. The default is now 10/Ha.
